# Week 9 — The Plan to Keep Building

## Where the next case study goes

The next case study will be added to the **Cases / Projects** section of my personal portfolio and linked from the master portfolio repository.

I will reuse the same three-beat structure from Week 2:

1. **Problem** — What real problem did the project solve, and why did it matter?
2. **What I did** — What I designed, implemented, tested, and changed.
3. **What came of it** — The measurable result, working demo, evaluation result, or lesson.

### Steps to add a new case

1. Finish and verify the project.
2. Collect the repository, live demo, evaluation/test evidence, and one limitation.
3. Write the case using **Problem → What I did → What came of it**.
4. Add the case to the portfolio's Cases / Projects section.
5. Add the project and evidence link to this master repository's deliverables index.
6. Review the case against the existing identity, voice, and visual system before publishing.
